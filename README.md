# New Vision

Редактор Markdown на Tiptap и Electron. Рядом с текстом можно держать справочные файлы и просить ассистента править документ по частям.

## Что умеет

- Несколько документов во вкладках. Создать, открыть, сохранить и закрыть — в меню «Файл».
- Слева список открытых документов и контекст. Справа чат. Границы между ними тянутся.
- В контекст добавляются файлы `.md` и `.txt`. В запрос модели попадают только отмеченные. Имя файла открывает его рядом, только для чтения.
- Ассистент ходит в OpenRouter и меняет документ инструментами: читает блоки, заменяет один блок, вставляет, удаляет, правит ячейки и структуру таблиц. Весь файл он не переписывает.
- Правка подсвечивается в тексте. Один вызов инструмента — один шаг отмены.

## Настройка

Скопируйте `.env.example` в `.env` в корне проекта:

```
OPENROUTER_API_KEY=ключ
OPENROUTER_MODEL=идентификатор модели с openrouter.ai
```

Ключ остаётся в главном процессе Electron и не встраивается в окно редактора.

## Запуск

```
npm install
npm run dev
```

Откроется окно приложения.

## Сборка установщика

```
npm run dist
```

Установщик Windows появится в папке `release`. При установке можно выбрать каталог. Файл `.env` положите рядом с `New Vision.exe`: в собранное приложение ключ не входит.
